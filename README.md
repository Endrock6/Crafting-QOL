# crafting_qol

A Minecraft data pack that adds a pile of quality-of-life crafting and uncrafting recipes: stone tools from any stone variant, wool back into string, uncrafting glass/terracotta/banners/wool, smelting raw blocks, cheaper minecarts, and more.

Built in [MCreator](https://mcreator.net) and shipped behind a small NeoForge loader mod (`packloader`, generated by MCreator) so the pack loads in modded setups.

## Layout

- `src/main` — the data pack itself (`assets/`, `data/crafting_qol/recipe`, `advancement`)
- `elements/` — MCreator mod element definitions
- `crafting_qol.mcreator` — MCreator workspace file
- `packloader/` — NeoForge loader wrapper that forces data pack loading
- `gradle/`, `gradlew*` — Gradle wrapper

## Building

```
./gradlew build
```

The exported pack lands in `build/export/export.zip`. `./gradlew syncDataPack` copies it into `run/datapacks/` for testing.

## Notes

`.mcreator/` (local history, backups, caches) and build output are ignored and are not needed to build.
